# Superseded R4 study

This pack was not published. Its 33-page draft and nine built-in imagegen outputs
are retained as studies after the user requested a full high-level preproduction
plan, removal of the unnecessary stairs, stronger dirt/activity causality and
varied facial acting. No R4 image is selected for the next publication.

The published Bath Magic reference room was the stated visual assumption after
an optional model/reference question. Canonical measured house files were not
changed. The saved Blender outputs are camera/layout studies; the generated art
must not be described as measured-conforming geometry. Actual prompts, input
hashes and tool originals are preserved in generation-records.json.
