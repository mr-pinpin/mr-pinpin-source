# Acting is an event, not a default expression

For each shot write: stimulus → what this actor wants → action → visible change.
Give an eyeline target in the world. Mouth/brow details support the action;
do not give every actor matching eyebrows. Resting faces are allowed.

## Shot vocabulary and reference separation

Alternate geography, evidence and response: establishing view → feet/nose/leaf
insert → over-shoulder hypothesis → physical test → reaction → new spatial view.
Avoid consecutive full-cast frontal arrangements unless a concrete action needs
both views. Reverse angles retain the same axis/landmark; an axis crossing gets
an orienting wide view or an actual visible movement.

Identity inputs: approved character views, not the last generated group face.
Geometry input: the recorded camera guide or inspected panorama perspective.
Acting input: specific pose/action if needed, with its role explicitly stated.
Palette input: prior chapter finish, without donating its layout or expressions.
Each result is inspected against these separate claims. Failed candidates never
become the anatomy authority for the next generation.
