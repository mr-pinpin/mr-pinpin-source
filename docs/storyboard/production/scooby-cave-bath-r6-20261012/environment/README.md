# Lush-cave layout v1

[Open the interactive top-down plan](top-down-map.html). Day buttons overlay
journeys; chamber descriptions and lighting landmarks appear below the map.
The source is [cave-layout.json](cave-layout.json), reproducibly drawn by
`python3 create-map.py`. `layout-validation.json` checks route adjacency.

Seven underground nodes form a curved, gently descending chain:
C0 root entrance → C1 fern lobby → C2 glowberry gallery → C3 echo pool →
C4 root-divided stream fork → C5 blossom room → C6 daylight outlet.
A separate outdoor path joins both openings. Mama and supported PomPom can wait
in C1 while the scouts explore, then use the exterior route to the outlet stream.
T0 shower tree is outside beside the western entrance; lake is outside east.

Minecraft's lush-cave inspiration supplies botanical variety and ambient space:
moss, root systems, vine berries, flowering plants and clay shallows. See the
[official biome description](https://help.minecraft.net/hc/en-us/articles/360046470431-Minecraft-Types-of-Biomes)
and [official lush-cave feature](https://www.minecraft.net/pt-pt/article/around-block--lush-caves).
This is our own illustrated forest place; no game art, blocks or UI are imported.

Beneath the Roots supplies stone/material/light and patient underground
storytelling references. Its sacred mural cavern is a separate established place,
not this network. Its lamps, murals, offerings and chambers are not carried here.

`native/cave-cutaway-v1.png` and `native/cave-topdown-v2.png` in the parent pack
are rejected topology studies: pretty stacked side-cutaways do not satisfy the
map. `native/cave-overhead-v3.png` is a reviewed illustrated overhead concept,
not an approved reader scene or measured-location model. The authored JSON stays
spatial authority; later anchor images must preserve its connections and banks.

Use generous connected room volumes, clear dry walkways and two named skylights;
not every camera sees every room. No stairs/bridges/pit rescue. Floors slope
slightly, streams do not flow uphill. Daylight comes from mouths/skylights;
amber accent light comes from the fictional berry vines. No spawned torch lamps.
