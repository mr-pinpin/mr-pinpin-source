## Reading behavior

Library covers are native links to the localized HTML reader, opening a new tab
with `rel=noopener`. A separate labeled button retains the verified PDF download
and cancellation flow. PDF size appears with the PDF action, not the online page
count. The first visible shelf's covers load promptly; later covers stay lazy.

The reader gives the title image high priority and starts the first narrative
image immediately. Later image URLs remain deferred until IntersectionObserver
finds them within one viewport ahead; dimensions reserve their layout space.
Jumping to the last page requests its neighborhood without loading the skipped
middle pages. Unsupported observers fall back to native lazy image loading.
Explicit print preparation loads and decodes the complete chapter; print preview
and browser print also materialize deferred URLs. Reading makes no PDF/HF calls.
The change applies across chapters, preserving their published image bytes.
