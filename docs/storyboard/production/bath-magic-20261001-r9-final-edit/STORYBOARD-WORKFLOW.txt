numbered panels. Never crop, stretch, truncate captions, generate or retouch art.

default; set requireEveryScene=false for a shorter pre-production selection.

boards/manifest.json records language, number, path, sha256, width, height,
sceneStart, sceneEnd and each panel sceneId/x/y/width/height. It preserves exact
caption text, input paths/hashes, and plan/layout/tool/font hashes/Pillow version.
